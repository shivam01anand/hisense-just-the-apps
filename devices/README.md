|---|---|---|
| `hisense-hismarttv-a4/` | Hisense HiSmartTV A4 (xiaoyushan), sold as the 55U6G, India, Android TV 9 | Full setup tested 19-20 Oct 2026 |

Find your TV's name with `adb shell getprop ro.product.device`. Not listed? The prompt has your assistant
work out the list on your TV, checking each unfamiliar package before touching it. When it works, add a folder
here so the next person with your TV can skip that step.

The upstream project [cleanyourtv](https://github.com/Gathin23/cleanyourtv) has lists for 50+ other TVs,
including the Hisense SmartTV 4K FFM.
